# X corpus analysis

## Methodology

元TXTをPythonで全件parseし、post IDのSHA-256でtrain 1,486、development 176、final 162へ固定。本文を選別理由にしていない。主分析と初版STYLEはtrainのみ。最終holdoutは調整完了後の一回に限定。parser監査は[manifest](CORPUS_MANIFEST.md)、全統計は[quantitative tables](QUANTITATIVE.md)。

train全1,486件を、時刻順の125件以下の12batchに分け、新規Codex CLI sessionで意味分類した。modelはgpt-5.6-sol、reasoning high。各投稿のcategory、最大3mode、思考構造、口癖の機能を記録し、全indexの一致を検査。主作業セッションでtrainの時系列サンプルと各batchの知見を照合した。全件を人間が多重annotateしたgold datasetではない。定量集計はPythonで実施。

再現用の[train labels](eval/train_labels.jsonl)はindex/category/modesのみ。本文、post ID、URL、個人経験は含まない。コーパスhashが変わったら古いindex labelを再利用しない。意味分類の再生成は確率的で、固定labelsでの統計再計算とは別境界。

## Cleanup

URL、書き出しに由来する分割URLと末尾の省略記号、引用行、code fence、代表的shell command・ログ行、tag/mentionのみの行を自然文から分離。元TXTのbytesは変更しない。

意味分類は自然文1,330件、文脈依存の本人文114件、定型/campaign/告知調18件、ログ主体3件、本文・文脈のみ7件、外部引用4件、不確実10件。主集計は前二者の1,444件。告知調が自動生成かはTXTだけでは断定できず、Core根拠から保守的に除外した。

引用元、reply先、画像本体、repost flagの完備したmetadataがなく、作者帰属は推定を含む。スペック列挙が本人の比較かcopyか、短文が画像への反応か不明な例がある。media_onlyは厳密な添付件数ではなく自然文を抽出できない記録の区分。

ユーザー指定のweighted counterを使用し、X公式twitter-textとの完全互換は主張しない。途中切断・分割URLがあるため、raw export長は元投稿の正確な表示長とは限らない。自然文に286 unitsの記録が1件あるが、生成の280上限を緩和する根拠にはしない。

## Quantitative findings

自然文1,444件の平均77.715文字、中央値70、母標準偏差49.105。weighted平均140.704、中央値129、母標準偏差87.487。P10=30、P25=64、P75=218、P90=276.7、P95=279、P99=280。短文と上限近くの比較文が併存し、平均長へ全部を寄せる設計は合わない。

句点・疑問/感嘆・改行で区切る近似で一文投稿29.02%、40 units以下14.75%、200超29.64%。平均2.427文、文平均31.098文字。改行あり19.53%、段落平均1.123。厳密な構文解析ではなく、改行断片も一文相当。

「まあ」は約1割、「てか」「マジで」は約6%。毎回入れると過剰模倣になる。w笑いはLatin語の一部を除くと3.19%。句読点は普通に使われ、全部外すのも誤り。substring集計には「何でも」などが混ざるため、機能は意味分析で判断する。

## 口癖の機能

証拠Tはtrainのexport index。原文の再掲でなく構造を要約する。

| 表現 | 観測された働き・根拠 | 使わない条件 |
| --- | --- | --- |
| まあ | T1821=課題保留、T1595=現実的代案、T1276=用途範囲の限定、T365=結果受容 | 短い成功、速報、丁寧な感謝 |
| てか | T1783=優先順位再考、T1145=比較対象変更、T897=別の不満へ転換 | 最初から1論点だけ、正式依頼 |
| でも | T1819=価格への留保、T1490=統合案の副作用、T688=不具合があっても継続、T339=別方式へ転換 | 反例のない称賛、仕様だけの紹介 |
| あとは | 現状の価値を認め、残る不足へ絞る | 不足が不明、まとめるだけ |
| 個人的に | 体感・用途・好みを一般事実から区切る | 明確な仕様、全投稿の枕詞 |
| マジで | T1786=有用性、T1210=未修正への要求、T820=驚き、T553=称賛 | 無感情共有、弱い不満、対外文 |
| w | T1159=不具合を笑う、T888=興奮、T561=苛立ち緩和、T404=深刻さを下げる | 真剣な怒り、静かな不満、礼儀指定 |

「まあ=譲歩」だけで固定せず、先送り、受容、自分には不要という限定も扱う。自己反論は思考の転換がある時に発生し、本人風の装飾ではない。

## 思考構造と評価軸

操作回数、実作業の完遂、制限、カスタマイズ、連携、安定性、価格対用途、携帯性、更新・維持の手間を重視する。スペックの大きさをそのまま価値にしない。

| Pattern | Train evidence | 再現する要素 |
| --- | --- | --- |
| 用途→制約→代替→代替の手間 | T1659、T1596–1595、T420、T373、T294 | 目的、障害、暫定的な落とし所 |
| 比較→自分に必要なもの | T1519、T1505、T1326、T1319、T1229 | 比較軸を入力の用途へ限定 |
| 成功→別の欠点→再評価 | T1477、T1388、T929、T688 | 成功範囲と未解決部分 |
| 理想→代償→条件付き期待 | T1735–1736、T1782、T1550、T965 | 物理・価格・操作負担 |
| 問題→原因仮説→回避→自作/自動化 | T1127、T865–866、T564、T52 | 回避の可否・手間。入力にある段階だけ |
| 観測→疑問→検証待ち | T1679、T757、T427、T337、T313 | 不明点と判断を変える証拠 |

問題から自動化まで全段階を必ず含む投稿が主流という意味ではない。複数ポストに分かれる場合や代替方法で完結する場合があり、入力に応じた部分構造としてモデル化した。

## 時系列

Coreは用途適合、使い勝手、制約回避、留保後の暫定判断。専門語と常体、一言で止める投稿も複数時期に存在する。

2025-Q1のweighted平均140.679に対し2026-Q3は156.811、改行率16.48%→26.77%。しかしsoftware話題だけでは平均194.838→197.915。全体長文化の大きな部分は話題構成の変化で説明可能で、本人の常時長文化と断定しない。

最近はAIの実作業、指示遵守、消費量、残存不具合への着眼が増加。2025-Q4はgame、2025-Q1はhardwareが多い。局所的なメーカー批判、ゲーム用語、ミームは恒常ルールにしない。

最近「消えた」と高確度で言える口癖は特定できなかった。一期間0件でも少数例・topic偏りでは消失を証明できない。むしろ/もはや等は全体でも少なく、未観測を禁止語にしない。一時流行は製品発表・ゲーム更新・AI障害に連動する話題語として扱う。

## Mode comparison

20modeの長さ、文数、語彙、語尾、句読点、改行、疑問、不確実性、技術密度、自己修正、罵語、箇条書き、皮肉/humor共起は[mode tables](QUANTITATIVE.md)。

技術467、比較363、仮説190等は反復が多い。対外文26、自虐15、激怒20は少なく、同じ確信度にしない。平常46は無感情文章の総数ではなく、分類者が優先modeとして付けた数。multi-label合計は総投稿数に一致しない。

語彙温度は文脈依存。「かなり」は程度、「めっちゃ」は口語の強調、「マジで」は実感・驚き、「ガチで」は真実味。具体的不満と罵語を分ける。機械的な5段階辞書に固定せず、入力感情とmodeの組で制御する。

| 期待→落差、反語 | T1269、T1587。矛盾を笑い/皮肉にする |

| 自虐 | T1510、T1508、T31、T6。不運のT1629とは別 |
| ミーム・語呂 | T1568、T649、T205。topic依存で汎用性は低め |
| 擬人化・自己戯画 | T834、T241、T321。冗談と事実の境界 |

皮肉と直接の罵倒を分ける。wは約3%で、毎回の締めにはしない。AI臭回避は作者判定や検出器対策ではなく、原文に少ない序論、網羅、お世辞、まとめの自動追加を防ぐための規則。

## 誤字と口語

んよね/なあ/てか等の反復口語は保持。一方、T1638の受動形、T1470の製品名、T1323の重複、T1061のOS名、T1063の反復、T731・631の表記は散発的で文体へ採用しない。「永遠と」は複数例でも意味上の誤用であり、頻出だけで安定口語に格上げしない。方言性は言語形式の観察に限り、出身地を推測しない。

## 限界と追加コーパスの優先順位

1. **対外文・丁寧な不同意**: 感謝以外の訂正依頼・断り・軽い反対で、常体との切替条件を確認。
2. **技術以外のhumor/自虐**: 技術・game用語やミームに頼らない笑いの配置。
3. **悲しみ・真剣な個人話**: 十分なmode数がなく、怒りや不満から外挿できない。
4. **怒りのない意見対立**: 不同意を常に攻撃的にする誤差を下げる材料。
5. **中立の長めの説明**: 作者帰属と文脈の明らかな例で告知/テンプレートと区別。

画像・返信先・引用欠損、時間の偏り、semantic label誤差、同一topicのtrain/holdout共有が限界。句数・語彙の計測は形態素解析ではない。未知topicはsynthetic testsとfinal reconstructionで別評価し、第三者による本人らしさの人間評価は未実施。
